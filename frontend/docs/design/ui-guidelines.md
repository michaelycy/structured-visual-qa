# 前端 UI 契约

> 版本：1.4（2026-08-21）  
> 状态：实施中  
> 视觉基线：用户提供的两张 1440 px 宽 UI 视觉参考图  
> 适用范围：`frontend/` 的应用外壳、管理页面与工作台业务组件

本文档是实现和验收约束，不是视觉建议。“必须”表示合并前必须满足；“应”表示
无页面级例外时必须满足；“可以”表示允许选择。参考图只用于提取视觉规范，不能
作为当前系统的信息架构、功能范围、字段、操作或页面结构设计。

### 参考图使用边界

| 可以提取 | 不得照搬 |
| --- | --- |
| 字号、字重、行高 | 页面名称、菜单名称和菜单数量 |
| 间距、对齐、留白与信息密度 | 文件夹、分类、字段和示例数据 |
| 控件高度、图标尺寸、圆角与边框 | 必须使用表格、卡片、Tab 或双侧栏的结论 |
| 色彩层级、阴影强度和状态表达方式 | 新建、删除、下载、启停等具体业务能力 |
| 响应式比例和视觉节奏 | 参考产品的用户流程与权限模型 |

页面采用什么组件、展示什么字段、允许什么操作，必须从当前仓库的业务能力、数据
契约和用户任务出发决定；确定组件类型后，再套用本文对应的视觉规格。

## 1. 设计原则

系统定位为企业级文档质检工具，采用 **高密度、低装饰、强层级、证据优先** 的
桌面工作台风格。

1. 页面骨架和信息层级必须稳定，用户切换页面后无需重新学习布局。
2. 边框和留白负责分区，阴影只用于浮层；不得用大量卡片堆叠制造层级。
3. 业务状态比装饰更醒目，颜色只表达主操作、选择或业务语义。
4. 默认面向 1280–1600 px 桌面窗口，同时保证 768 px 窄屏可完成核心操作。
5. 本契约的明确数值优先于通用组件默认值；标记为“Ant Design 默认”的项目，
   指当前锁定版本、全局主题和 `middle` 密度共同产生的默认值，页面不得二次覆盖。

### 1.1 业务辨识度

界面的辨识度来自质检证据，而不是装饰：文档对必须清楚表达源文档到目标文档的
关系；状态、分数和问题数量形成稳定扫描顺序；配置、语言对、运行时间和人工复核
属于可追溯证据。不得为制造差异化引入与任务无关的渐变、纹理或大幅装饰动效。

## 2. 基准画布与页面骨架

两张参考图共享 1440 px 桌面画布，可用于校准应用外壳的比例、密度和对齐基线；
这不意味着当前系统必须照搬其双侧栏、表格或卡片结构。当前系统选用对应区域时，
按以下尺寸实现：

| 区域 | 契约尺寸 | 规则 |
| --- | ---: | --- |
| 顶栏 | 72 px 高 | 固定在顶部，底部 1 px 边框 |
| 一级侧栏 | 260 px 宽 | 品牌、一级导航、底部用户区 |
| 二级侧栏 | 256 px 宽 | 仅用于项目树、目录树等层级导航 |
| 一级侧栏底部用户区 | 68 px 高 | 仅在系统存在用户身份时显示，固定底部 |
| 内容工具栏 | 68 px 高 | 搜索、筛选、排序、视图切换 |
| 表格表头 | 内容自适应 | 使用锁定版本的 Ant Design Table `middle` 默认样式 |
| 表格数据行 | 内容自适应 | 14/22 px，可随内容自然增高 |
| 表格分页栏 | 64 px 高 | 左侧统计，右侧分页 |

### 2.1 布局组合

```text
┌──────────────────────────────────── 72 px 顶栏 ────────────────────────────────┐
│ 品牌区 260 │ 页面标题 / 数量                         │ 页面主操作            │
├────────────┼────────────┬──────────────────────────────────────────────────────┤
│            │ 二级导航   │ 68 px 搜索 / 筛选 / 视图工具栏                      │
│ 一级导航   │ 256 px     ├──────────────────────────────────────────────────────┤
│ 260 px     │ 可选       │ 自适应表头                                           │
│            │            ├──────────────────────────────────────────────────────┤
│            │            │ 内容自适应数据行                                      │
│            │            ├──────────────────────────────────────────────────────┤
│ 用户区     │            │ 64 px 统计 / 分页                                   │
└────────────┴────────────┴──────────────────────────────────────────────────────┘
```

- 没有目录树的页面必须省略二级侧栏，内容区直接占用剩余宽度，不保留空列。
- 顶栏、侧栏和表格表头可以吸顶；不得让页面标题随数据区滚出后完全失去上下文。
- 主内容区最小可用宽度为 720 px。低于该宽度时进入响应式规则，不继续压缩表格。
- 表格型管理页使用全部可用宽度。规则、表单等卡片型管理页可以设置 1024 px
  内容宽度并左对齐，距内容区左侧 32 px；报告阅读页可以限制正文宽度，但证据
  对照区除外。

## 3. 间距契约

所有间距使用 4 px 基础网格，2 px 仅用于图标内部或紧凑标签微调。

| Token | 数值 | 典型用途 |
| --- | ---: | --- |
| `--qa-space-0-5` | 2 px | 图标与状态点的光学校正 |
| `--qa-space-1` | 4 px | 紧凑标签、相邻辅助文字 |
| `--qa-space-2` | 8 px | 图标与文字、同组控件间距 |
| `--qa-space-3` | 12 px | 菜单图标与文案、紧凑单元格 |
| `--qa-space-4` | 16 px | 按钮水平内边距、侧栏左右内边距 |
| `--qa-space-5` | 20 px | 页面标题内部间距、表格操作组 |
| `--qa-space-6` | 24 px | 内容工具栏和表格单元格水平内边距 |
| `--qa-space-8` | 32 px | 顶栏页面标题左右内边距 |
| `--qa-space-10` | 40 px | 大区块之间的最大常规间距 |

### 3.1 强制间距

- 一级侧栏左右内边距必须为 16 px；分组标题左右内边距可以为 28 px。
- 顶栏内容区水平内边距必须为 32 px；紧凑窗口下降为 24 px。
- 内容工具栏水平内边距必须为 24 px，控件间距为 16 px，同组图标按钮间距为 8 px。
- ≥768 px 时数据单元格水平内边距必须为 24 px，操作列可以降至 16 px；
  <768 px 时可以降至 8 px。表头内边距由锁定版本的 Ant Design Table
  `middle` 密度生成，不做页面级覆盖。
- 页面区块垂直间距使用 24 px；不得出现 18、22、26、30 px 等临时数值。
- 行内图标与文本间距使用 8 px，状态圆点与状态文字间距使用 6 px。

## 4. 字体契约

字体使用系统字体栈：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、
`PingFang SC`、`Microsoft YaHei`。不得为单一页面加载额外 Web Font。

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | ---: | --- |
| 产品名 | 18 / 26 px | 600 | 顶栏品牌名 |
| 页面标题 | 16 / 24 px | 600 | 一级页面标题 |
| 区块标题 | 14 / 22 px | 600 | 面板、列表区标题 |
| 正文 / 表格 | 14 / 22 px | 400 | 文件名、主要数据、表单值 |
| 导航项 | 14 / 20 px | 400；选中 500 | 一级、二级导航 |
| 表头 | 锁定版本默认 | 锁定版本默认 | 由 Ant Design Table `middle` 密度管理 |
| 辅助信息 | 12 / 18 px | 400 | 表单帮助、补充说明、非关键统计 |
| 标签 / 状态 | 12 / 18 px | 500 | 语言对、状态、严重度 |
| 极小注释 | 11 / 16 px | 400 | 仅允许头像角色等低优先级信息 |

- 普通页面不得使用超过 24 px 的标题；报告分数等数据展示属于例外。
- 正文不得小于 12 px，11 px 只能用于非关键辅助信息。
- 时间、大小、数量均使用 14 / 22 px，只通过文字颜色建立层级；表头使用锁定版本
  Ant Design Table `middle` 密度的默认字号、行高、字重和颜色。
- 表格数字应启用等宽数字特性：`font-variant-numeric: tabular-nums`。
- 单行文本默认省略，悬停显示完整内容；不得通过压缩字号容纳长文件名。

## 5. 圆角契约

圆角只允许以下档位：

| Token | 数值 | 用途 |
| --- | ---: | --- |
| `--qa-radius-xs` | 4 px | 标签、状态底、计数标记 |
| `--qa-radius-sm` | 6 px | Checkbox、紧凑控件 |
| `--qa-radius-md` | 8 px | 按钮、输入框、菜单选中项、普通面板 |
| `--qa-radius-lg` | 12 px | Modal、Drawer、独立大型容器 |
| `--qa-radius-full` | 999 px | 头像、状态点、真正的胶囊标签 |

- 页面不得新增 5、7、10、14、16 px 等圆角值。
- 普通按钮和输入框必须为 8 px，不使用全圆角胶囊按钮。
- 卡片或面板默认 8 px；浮层、视觉上独立的大型容器以及规则配置卡片使用 12 px。
- 表格本体不逐行加圆角；圆角只存在于表格外容器的四个角。

## 6. 颜色与表面

色彩继续使用当前系统已确认的业务色板，参考图不覆盖既有状态语义。

| 语义 | 强调色 | 可读文字色 | 浅背景 | 用途 |
| --- | --- | --- | --- | --- |
| 页面背景 | `#F9F9FB` | — | — | 主内容区背景 |
| 侧栏 | `#14181E` | — | — | 一级导航背景 |
| 严重 | `#FF5252` | `#B42318` | `#FFEAEA` | 未通过、严重问题 |
| 一般 | `#FFA94D` | `#8A4500` | `#FFF1E1` | 需复核、警告 |
| 通过 | `#00A878` | `#006B4D` | `#E5F7F0` | 通过、完成、成功 |
| 信息 | `#1F6FEB` | `#174EA6` | `#E5EEFE` | 主操作、链接、选中状态 |
| 主文字 | `#18191C` | `#18191C` | — | 标题、正文 |
| 次要文字 | — | `#5F6B7A` | — | 时间、数量、说明 |
| 弱提示 | `#8A94A3` | — | — | 深色侧栏辅助字、非文字图形；不得作为白底小字号文字 |
| 边框 | `#E8EBEF` | — | — | 分隔线、输入框、表格 |
| 表面 | `#FFFFFF` | — | — | 顶栏、内容面板、表格 |

- 业务组件必须从 `uiTokens.ts` 读取颜色，CSS 必须使用 `--qa-*` 变量。
- 禁止在页面组件中写十六进制、RGB、Ant Design 预设色名或透明黑灰。
- 状态不能只靠颜色区分，必须同时显示中文文案；状态圆点使用强调色且直径为
  6 px，状态文字必须使用对应的可读文字色。
- 普通表面不使用阴影。阴影仅用于 Dropdown、Popover、Modal 和悬浮操作条。
- 分区边框统一为 1 px；不得用 2 px 以上边框制造常规层级。

## 7. 控件尺寸

| 控件 | 可见尺寸 | 圆角 | 内部规则 |
| --- | ---: | ---: | --- |
| 主/次按钮 | 36 px 高 | 8 px | 水平内边距 16 px，图文间距 8 px |
| 搜索框 / Select | 36 px 高 | 8 px | 水平内边距 12 px |
| 图标按钮 | 36 × 36 px | 8 px | 图标 16 px，交互热区至少 44 × 44 px |
| 一级菜单项 | 40 px 高 | 8 px | 左右 12 px，图标 18 px |
| 二级菜单项 | 38 px 高 | 8 px | 左右 12 px，图标 16 px |
| Checkbox | 16 × 16 px | 4 px | 与文字间距至少 12 px |
| 紧凑标签 | 20 px 高 | 4 px | 水平内边距 6 px |
| 头像 | 32 × 32 px | 999 px | 仅显示真实头像或姓名首字母 |
| 分页按钮 | 32 × 32 px | 8 px | 当前页使用信息蓝填充 |

- 同一工具栏不得混用 32、36、40 px 三种控件高度。
- 图标按钮必须提供 Tooltip 和 `aria-label`；不得使用 Emoji 或字符模拟图标。
- 可点击区域小于 44 px 时，必须通过伪元素或外层容器扩大热区且不改变视觉尺寸。
- Hover、Active、Focus、Disabled、Loading 五种状态必须完整；焦点环使用信息蓝。

## 8. 顶栏与导航

### 8.1 顶栏

- 品牌区宽度必须与一级侧栏一致，品牌图标 24 px，产品名 18 px。
- 页面标题与数量在同一行：标题 16/600，数量 12/400，两者间距 8 px。
- 页面主操作置于右侧，距离窗口右边 32 px；一个页面最多一个高强调主按钮。
- 顶栏不得同时出现面包屑、一级标题、二级标题三套导航表达。

### 8.2 一级侧栏

- 导航分组间距 28 px，分组标题 12 px / 500，使用次要文字色。
- 菜单项垂直间距 4 px。选中项使用信息蓝或信息浅蓝背景，并保留中文标签。
- 选中项左侧可以使用 3 px × 24 px 指示条；若使用实色蓝底则不重复添加指示条。
- 一级菜单顺序稳定，不因页面状态动态重排。

### 8.3 二级侧栏

- 只用于项目、文件夹、目录树等真实层级，不作为所有页面的装饰性空侧栏。
- 标题区高 44 px，树节点高 38 px，节点间距 4 px。
- 数量标记使用 20 px 高、4 px 圆角；新增操作使用 16 px 图标按钮。

## 9. 表格契约

管理列表必须使用 Ant Design Table，并通过 `DataTable` 基础组件统一配置。

### 9.1 尺寸

- 表头和数据单元格禁止设置固定高度；高度由字号、行高、内边距和内容自然形成。
- 表头的字号、行高、字重、颜色、背景和内边距使用锁定版本、全局主题与
  `middle` 密度共同产生的默认值，禁止在 `DataTable` 或页面 CSS 中覆盖。
- 数据单元格使用 14/22 px；垂直内边距使用 Ant Design Table 默认密度。
  内容换行或浏览器放大时必须允许行高自然增长。
- 分页栏视觉高度可以保持 64 px，因为它不承载可变长度的单元格内容。
- 存在批量操作时才启用选择列；启用后首列选择框在桌面端距离表格左侧 24 px。
  普通单元格桌面端左右内边距 24 px，移动端可以降至 8 px。
- 文件图标为 20 px，图标与文件名间距 8 px。
- 状态列最小宽度 96 px；日期列最小宽度 132 px；操作列固定在右侧。
- 同一表格使用一致的单元格内边距；禁止为维持视觉高度而缩小字号、裁切关键内容
  或强制把多行内容压回单行。

### 9.2 行为

- 默认每页 10 条；启用批量选择时显示“已选择 N 项，共 N 项”，否则显示
  “共 N 条”。
- 整行 Hover 只改变浅背景，不移动、不放大、不出现阴影。
- 表头可以排序时必须显示排序图标；当前排序状态不能只在后端生效而无视觉反馈。
- 文件名等长文本单行省略，Tooltip 展示完整值。
- 时间和日期列不得换行；列宽必须容纳页面采用的完整时间格式，不得通过缩小字号
  或裁掉时间精度换取单行展示。
- 搜索必须可清除，筛选默认值为“全部…”，视图切换按钮为互斥选中状态。
- 行内图标操作最多 3 个；超过 3 个进入“更多”菜单。
- 删除、归档等破坏性操作必须二次确认；详情、下载等图标必须有 Tooltip。
- 横向空间不足时表格滚动，操作列固定；启用选择列时选择列也必须固定。不得把
  正文压缩到 12 px 以下。
- `scroll.x` 只能表示列内容可用的最小宽度，不得用大于实际列需求的固定值强制
  常规桌面视口出现横向滚动；容器宽度达到最小宽度后，滚动区域宽度必须等于容器。

## 10. 卡片型内容视觉规格（条件适用）

本节不规定规则管理或任何具体页面必须使用卡片。只有当当前业务分析确认卡片比
表格、表单或树形结构更合适时，才应用以下视觉规格。

### 10.1 紧凑卡片尺寸

| 视觉元素 | 契约尺寸 | 适用说明 |
| --- | ---: | --- |
| 单标题 + 单行描述卡片 | 90 px 高 | 内容增加时允许统一提升为 112 px |
| 卡片间距 | 16 px | 同一列表保持一致 |
| 卡片水平内边距 | 20 px | 左右内容按同一基线对齐 |
| 前置图形容器 | 40 × 40 px | 可选；8 px 圆角、图标 16 px |
| 标题 | 16 / 24 px | 600，默认单行 |
| 描述 | 14 / 22 px | 次要文字色，默认单行省略 |
| 辅助标签 | 20 px 高 | 可选；4 px 圆角 |
| 尾部标准控件 | 36 px 视觉高度 | 控件类型由真实业务决定 |

### 10.2 卡片布局

- 卡片使用白色表面、12 px 圆角和 1 px 边框，不默认使用阴影。
- 可选区域依次为前置图形、主要内容、辅助信息和尾部操作；未使用的区域必须删除，
  不能为了接近参考图放置无业务意义的图标、标签或开关。
- 主要内容占据剩余宽度；长标题优先省略，不能挤压真实业务操作。
- Hover 仅改变边框或浅背景，不移动、不放大卡片。
- 使用 Switch、状态或图标按钮时，仍须遵守本文的状态文案和可访问性规则；本文
  不据此推导系统必须具备启停、更多菜单或删除等功能。

### 10.3 筛选区与响应式

- 如果页面存在分类筛选，Tab 视觉高度为 36 px、文字 14/20 px、间距 8 px；
  这不构成必须新增分类功能的要求。
- 如果页面存在搜索，沿用 36 px 控件高度，宽度由实际字段和页面空间决定，不固定
  为参考图的 256 px。
- 768–1023 px 时卡片宽度改为 100%；< 768 px 时允许统一提升卡片高度并让可选
  区域换行，但不得隐藏当前业务所需的操作和状态。

## 11. 页面容器与基础组件

| 组件 | 契约职责 | 禁止行为 |
| --- | --- | --- |
| `PageHeader` | 页面标题、数量、一个主操作 | 重复显示侧栏导航 |
| `PageSection` | 内容分区、区块标题和局部工具栏 | 再套同形 Card |
| `DataTable` | 密度、分页、空状态和条件式选择能力 | 页面私自覆盖表头或密度 |
| `StatusTag` | 状态文案、圆点和语义色 | 页面自行映射颜色 |
| `EmptyState` | 初始无数据、筛选无结果 | 只有“暂无数据”无下一步 |
| `FormDrawer` | 创建、编辑类表单 | 放置无关的浏览型内容 |

- 基础组件位于 `frontend/src/components/ui/`，视觉变量集中在 `global.css` 和
  `uiTokens.ts`。
- 基础组件只定义视觉与交互结构，不请求接口、不保存业务状态。
- 页面只能组合基础组件或声明明确的页面级变体，不复制基础组件 CSS。
- 一级菜单必须使用 TanStack Router 路由，选中状态来自当前 URL；服务端数据必须
  通过 `services/` 和 TanStack Query 获取，页面与组件禁止直接调用 `fetch`。

## 12. 状态、反馈与动效

- 文档状态统一为“通过 / 需复核 / 未通过”，禁止展示 `pass/review/fail`。
- 业务执行统一使用“质检”；仅在解释算法关系时使用“比较”或“对比”。
- Hover/Focus 过渡时长为 150 ms；抽屉和弹窗进入为 200–240 ms。
- 只允许 `opacity` 和 `transform` 动画，避免通过 width/height 动画引发布局抖动。
- 必须支持 `prefers-reduced-motion`；关闭动效后不能影响状态反馈。
- 加载使用 Skeleton、Spin 或控件 loading；不得让表格清空后无反馈。
- 初始无数据与筛选无结果必须使用不同文案，并提供可执行的下一步。
- 错误信息必须说明失败对象和处理建议，不直接展示后端堆栈。

## 13. 响应式契约

| 视口宽度 | 行为 |
| --- | --- |
| ≥ 1280 px | 完整顶栏 + 260 px 一级侧栏；需要时显示 256 px 二级侧栏 |
| 1024–1279 px | 一级侧栏可收起为 72 px 图标栏；二级侧栏保持 240 px |
| 768–1023 px | 一级侧栏收起；二级侧栏改为 Drawer；页头工具栏允许换行 |
| < 768 px | 使用移动顶栏与抽屉导航；表格保留关键列，其余进入详情或横向滚动 |

- 断点必须全局统一，不得由页面自行创造 760、820、900 等近似断点。
- 768 px 以下，搜索框占整行，筛选和视图按钮在下一行排列。
- 任何视口下，主操作、筛选、详情和复核入口都必须可触达。
- 必须在 375、768、1024、1280、1440 px 五个宽度检查布局。

## 14. 可访问性

- 正文与背景对比度至少 4.5:1；大字号文本至少 3:1。
- 颜色不得是状态的唯一载体，状态必须同时包含文字或图标。
- 所有功能可通过键盘完成，焦点顺序与视觉顺序一致；不得移除焦点环。
- 图标按钮必须有可访问名称；图片必须有与业务用途一致的替代文本。
- Tooltip 不能承载完成任务所必需的唯一信息。
- 启用批量选择时，表格 Checkbox 必须有行级标签，批量操作必须显示已选数量。

## 15. 实现映射

Ant Design 全局 Token 至少统一为：

| Ant Design Token | 契约值 |
| --- | ---: |
| `fontSize` | 14 px |
| `fontSizeSM` | 12 px |
| `controlHeight` | 36 px |
| `controlHeightSM` | 32 px |
| `borderRadius` | 8 px |
| `borderRadiusLG` | 12 px |
| `lineWidth` | 1 px |
| `colorPrimary` | `#1F6FEB` |
| `motionDurationFast` | 150 ms |
| `motionDurationMid` | 200 ms |

实现时必须优先修改全局 Token 和基础组件，不允许逐页用 `style={{...}}` 修补。
确需偏离契约时，必须在页面组件旁声明原因、适用范围和回收条件。

### 15.1 Tailwind CSS v4

- 使用官方 `@tailwindcss/vite` 插件和 CSS-first 配置，不新增 `tailwind.config.js`。
- 所有工具类使用 `tw:` 前缀；例如 `tw:flex`、`tw:gap-qa-2`、
  `tw:bg-qa-canvas`、`tw:rounded-qa-md` 和 `tw:text-qa-body`。
- 关闭 Preflight，避免全局元素重置影响 Ant Design；`global.css` 继续承担基础样式。
- 默认颜色、字号、间距、圆角、阴影和断点命名空间必须清空，只暴露映射到
  `--qa-*` 的契约 Token。禁止使用任意值语法绕过契约。
- Tailwind 负责 display、Flex/Grid、布局间距和响应式组合；Table、Form、Drawer、
  Modal、状态语义和复杂交互仍由 Ant Design 与基础组件负责。
- 页面迁移必须按需进行，不因接入 Tailwind 而批量重写已经验收的 CSS。
- 条件类名和外部 `className` 统一使用 `frontend/src/lib/cn.ts` 的 `cn()` 合并；
  该函数负责条件展开，并按 `tw:` 前缀消除 Tailwind 同组冲突。禁止重复实现
  数组 `join` 或字符串拼接工具。
