# 真实 PDF 规则校准记录

## 1. 校准目标

本轮校准用于验证当前 PDF MVP 在真实中英文翻译文档中的误报情况，重点检查：

- 背景图上的正常叠字是否被误判为文字图片重叠；
- 中英文 PDF 文本框切分不同是否被误判为内容缺失；
- 图表标签等大量小 Region 是否造成重复扣分；
- Critical 是否只对应明显影响交付的可见异常。

本轮不校准 OCR、表格结构和语义翻译质量。

## 2. 样本

样本使用联合国驻华系统公开发布的《2024 Annual Country Results Report》英文版和中文版：

- 页面数：英文 46 页，中文 46 页；
- 页面尺寸：均为 1207.5 × 825 PDF point；
- 文件类型：机器生成 PDF；
- 版式特征：照片背景、图片叠字、双栏内容、图表、小字号标签和复杂拼贴页面；
- 视觉结论：抽查封面、正文、图文混排、图表和背景图页面，两个版本整体版式一致，没有发现明显裁切或不可读内容。

真实 PDF 现作为 Golden Sample 存放于 `examples/`（随仓库提交，见 `AGENTS.md`）；自动测试使用运行时生成的合成 PDF，避免依赖第三方文档。

## 3. 基线结果

初始规则输出：

```text
状态             FAIL
文档分数         20.17
失败页面         44 / 46
Critical         207
text/image 重叠  196
missing element  51
```

该结果与页面渲染图严重不一致，属于系统性误报。

## 4. 根因与调整

### 4.1 背景图片叠字

原规则只判断目标页面两个 BBox 是否相交，因此封面标题、照片署名和背景色块上的文字都会触发 Critical。

调整为比较 Source 与 Target 的拓扑变化：

- Source 和 Target 都存在的图片叠字不报告；
- 只有 Target 文字中心新进入图片，且重叠显著增加时才报告；
- 面积不超过页面 0.5% 的照片署名、版权来源等小型 Caption 不报告。

### 4.2 跨语言文本框合并

英文版经常把相邻段落导出为多个 PDF Block，中文版可能把它们导出为一个大文本框。一对一匹配后，多余英文 Block 会被误判为缺失。

调整为：未匹配源文本若被目标文本 Region 覆盖至少 40%，则视为跨语言多对一合并，不产生 `MISSING_ELEMENT`。图片仍执行严格一对一缺失检测。

### 4.3 字号缩小严重度

跨语言字体的 PDF point 不具备完全相同的视觉含义。仅凭字号比例不能证明内容丢失。

调整为：单独的 `FONT_SHRINK` 最高为 High；如果同时出现裁切或越界，由对应规则产生 Critical。

### 4.4 重复标签扣分

图表标签可能被拆成十几个 Region，同一种视觉变化会被重复扣分，导致页面分数降至 0。

调整为按 Issue 类型设置页内扣分上限：

- 所有 Issue 仍完整保留；
- High 仍可触发 `REVIEW`；
- Critical 仍可直接触发 `FAIL`；
- 同类解析碎片不再无限重复扣分。

## 5. 校准后结果

> 版本说明：本节「REVIEW / 91.80 / Critical 0」是校准早期的历史快照（仅布局类检测器的规则版本）。当前默认 Profile（`translation-balanced@1`）在同一批 UN China 2024 样本上的基线为 **FAIL / 86.80 / 119 issues**（已加入内容级数字/漏译与术语检测），见 `docs/todo/tech-adoption-plan.md` 的落地记录。

```text
状态             REVIEW
文档分数         91.80
通过页面         27 / 46
复核页面         19 / 46
失败页面         0 / 46
Critical         0
High             39
Medium           54
Low              3
```

校准后结果符合保守 QA 预期：不再把正常设计判为失败，同时保留字号变化、区域偏移和少量未匹配元素供人工检查。

## 6. 回归测试

新增测试覆盖：

- 跨语言多个源段落合并到一个目标文本框；
- Source 与 Target 都存在的背景图叠字；
- Target 新出现的文字图片重叠；
- 重复同类 Issue 的页内扣分上限。

## 7. 当前限制

本轮只有一组 46 页真实文档，不能代表所有 PDF 生成器和版式。下一轮至少应增加：

1. Word 导出的双语报告；
2. PowerPoint 导出的双语演示文档；
3. 含真实表格、页眉页脚和脚注的文档；
4. 人工注入重叠、裁切、缺图和字体缩小的缺陷样本；
5. 每类问题至少 20 个阳性和 20 个阴性页面。

只有建立人工标注集后，才能计算 Precision、Recall、F1，并确定生产阈值。当前阈值属于 MVP 校准值。
